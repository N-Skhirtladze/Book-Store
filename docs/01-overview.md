# Book Store

## Project Description

Book Store is a full-stack web application that allows users to browse and discover books, view detailed information about them and rate books based on their experience.

The application also includes an administrative interface for managing books and related application data. In addition, the project will include a simple AI assistant to help users interact with the book store and discover relevant information.

## Project Goal

The main goal of this project is to build my first complete full-stack web application from the ground up.

Through this project, I aim to:

- Practice building a complete CRUD application
- Learn and use TypeScript in both the frontend and backend
- Implement user registration and authentication
- Understand authorization and role-based access control
- Work with JWT-based authentication
- Design and work with a relational database
- Build and consume a REST API
- Integrate a basic AI API for a chat assistant
- Learn to use Git and GitHub in a more professional and structured way
- Practice developing a project using issues, branches, commits, and pull requests
