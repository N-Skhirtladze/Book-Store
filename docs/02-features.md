# Features

## Guest

- Browse books
- Search books 
- Filter books
- View book details
- View ratings
- Register an account
- Log in to an account
- Use the AI assistant

## Registered User

- Manage account
- Add and remove books from favorites
- Rate books
- Write reviews 
- Edit own reviews
- Delete own reviews
- Add books to cart
- Complete the checkout process
- View order history
- Use the AI assistant

## Administrator 

- Add Book
- Change Book Detail 
- Delete Book
- Manage book data
